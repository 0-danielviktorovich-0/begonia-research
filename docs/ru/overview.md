# begonia-research — база знаний по Redmi Note 8 Pro

**Язык:** [Русский (эта страница)](overview.md) · [English](../../README.md)
**Каталог:** [Поиск по темам — RU](index.md) · [Topic directory — EN](../en/index.md)

Исследовательская база по **Xiaomi Redmi Note 8 Pro (begonia/begoniain, MediaTek MT6785 / Helio G90T)**: MIUI и кастомные Android-прошивки, CFW/Non-CFW, ядра Linux 4.14/4.19 и 6.x/7.x, драйверы, Ubuntu Touch, Droidian, postmarketOS, восстановление телефона, KernelSU/Magisk и средства разработки с ИИ.

> **Состояние перевода:** база начиналась как англоязычное исследование; некоторые новые главы (19–22) были первоначально написаны по-русски. Сейчас у каждого материала есть **русский маршрут поиска и краткое русское описание**, но не каждый длинный технический документ переведён полностью. Неполные переводы явно отмечены; они не выдаются за полноценные. Реестр статусов — [i18n/catalog.json](../../i18n/catalog.json). Оригиналы и ссылки на доказательства доступны в любой языковой версии.

**Проект реорганизации репозитория:** [полный план на русском](architecture/repository-refactor-plan.md) · [English RFC](../en/architecture/repository-refactor-plan.md) · [машинная карта перемещений](../../data/catalog/path-migrations.json). **Массовый перенос пока не выполнен**: старые пути остаются рабочими до проверки ссылок и инструментов Hermes.

## Как устроена мультиязычность

- **Английский (en)** — язык основной международной документации и названий машинных интерфейсов.
- **Русский (ru)** — полноценная навигация, ключевые определения и терминология, с приоритетом для русскоязычных участников.
- Оригинал технического документа остаётся **единственным источником фактических изменений**, пока проверенный полноценный перевод не подготовлен. У глав 19–22 пока оригинал на русском; это честно зафиксировано и не отменяет общей английской структуры.
- Названия разделов в переводах могут быть естественными для языка, но **команды, пути, Git SHA, имена разделов памяти, номера ошибок, идентификаторы кода, URL и версии ПО не переводятся**.
- У каждого перевода должен быть проверенный исходный коммит, ссылка на оригинал и статус готовности. Правила работы для людей и ИИ-агентов — [i18n/README.md](../../i18n/README.md), [i18n/TERMINOLOGY.md](../../i18n/TERMINOLOGY.md).

## Что важно для безопасной разработки

Текущее неизвестное Android-окружение пользователя **не трогать до инвентаризации**. Прошивки, найденные на GitHub/4PDA/XDA, не равнозначны проверенным образам для всех региональных и аппаратных вариантов begonia. Наличие ядра MT6785 4.19 для родственного устройства rosemary само по себе не доказывает, что его можно загрузить на begonia. Автоматические методы unbrick тоже не гарантированы.

**Исследование не является инструкцией «прошивать всё подряд».** См. [безопасный preflight](../en/recovery/18-DEVICE-PREFLIGHT-READONLY.md) и [аудит достоверности](../en/research/17-INDEPENDENT-AUDIT.md).
