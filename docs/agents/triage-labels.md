# Triage Labels (default Matt Pocock vocabulary)

| Метка | Роль |
|---|---|
| needs-triage | новая задача, не разобрана |
| needs-info | не хватает данных от владельца/устройства |
| ready-for-agent | можно выполнять агенту |
| ready-for-human | требует человека (флеш, физика, аккаунты) |
| wontfix | осознанно не делаем |
