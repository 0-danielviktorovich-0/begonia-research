# Domain Docs — consumer rules (begonia-research)

- `GLOSSARY.md` (в корне) — термины проекта: устройства, прошивки, ядерные понятия, тулчейн.
  Термин без записи сюда считается неопределённым — при первом использовании добавить.
- `docs/adr/` — Architecture Decision Records: решения уровня «почему так, а не иначе»
  (выбор дерева, поколение ядра, тулчейн). Один ADR = одно решение, номер = дата.
- Источники истины для фактов устройства: docs/en/android/* (номерованные темы).
