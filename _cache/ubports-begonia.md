The issues listed below are present in most or all of the devices
depending on the technology they are built on.

- LTE calling (VoLTE) [![Bugtracker](https://devices.ubuntu-touch.io/_astro/gitlab.Cd_TTUTb.svg)](https://gitlab.com/ubports/ubuntu-touch/-/issues/1335)

Calling over VoLTE is experimental and depends on the cellular carrier, available bands and geographical region. Please check the requirements for your carrier and country.

## How to install Ubuntu Touch OS

You can install Ubuntu Touch on this device using the UBports Installer on
your computer.

Make sure the bootloader of your device is unlocked and that your
device has the required version of Android installed. Before
installing, follow the device-specific instructions below:

1. Please double-check that your device is a Xiaomi Redmi Note 8 Pro (begonia).
2. If you haven't done so already, make sure to OEM unlock your device first. [![download-icon](https://devices.ubuntu-touch.io/_astro/external-link.wS4l9fQ0.svg)](https://en.miui.com/unlock/download_en.html)

## Report an Issue for  Xiaomi Redmi Note 8 Pro

* * *

Did the maintainer say that feature ‘works’ but you know from doing it that
it really doesn’t?

Start by searching the
[device issue](https://gitlab.com/ubports/porting/community-ports/android10/xiaomi-redmi-note-8-pro/xiaomi-begonia/-/issues)
, if you found it, hopefully the porter is on it. 'Subscribe' to the issue in
case it get solved.

**Couldn't find it?**

Uh-oh… Well it is time to let the porter and everyone else know about the
fail and send the tech magic back to the workshop for a makeover.

1\. Read ' [Bug Reporting](https://docs.ubports.com/en/latest/contribute/bugreporting.html)' section in UBports docs on 'How to report a bug'.

2\. Then (this time), head to
[the device repository](https://gitlab.com/ubports/porting/community-ports/android10/xiaomi-redmi-note-8-pro/xiaomi-begonia/-/issues)
and submit it, so the porter knows about it.
