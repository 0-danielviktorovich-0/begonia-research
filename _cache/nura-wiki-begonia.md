## How to enter flash mode

- **Recovery Mode**: Hold Volume Up and Power while connecting the device to a computer with a USB cable.
- **Fastboot**: Hold Volume Down and Power while connecting the device to a computer with a USB cable. To shut down from fastboot, run `fastboot oem poweroff`.

## Installation

### Unlocking the bootloader

There are two methods, the option #1 is the manufacturer's recommended way but takes minimum several days to get the unlock key, while option #2 takes 5 minutes.

#### Option \#1: Mi Account and Windows

Sign up for a Mi Account, register your device in the settings, and wait for a week. [More info](https://forum.xda-developers.com/t/guide-begonia-unlock-bootloader-flash-twrp-and-root-proper.3995919)

Remark: I did not have a Windows machine, so started up a windows10 install in virt-manager and got it to work to unlock eventually:

1. Set the machine to use USB2 ports (not USB3);
2. Reboot the Windows 10 machine with signing disabled;
3. Install the [Xiaomi USB Drivers](https://www.xiaomidriversdownload.com/xiaomi-usb-drivers-official/?cn-reloaded=1#google_vignette) for flashing ( [MediaTek device](https://www.terabox.com/sharing/link?surl=EJGO0Mlo1hf1IXrKBFEXJQ)) for Windows (7 and above) (32/64-bit). Go to Device manager and install drivers manually for the Android device.
4. In the unlock tool, make sure to use the QR code in the upper left on the starting screen, the other method login failed to send an SMS in my case.

The official Xiaomi tool only runs on Windows, but [XiaoMiTool V2](https://www.xiaomitool.com/V2/) worked for me on Fedora Linux. Be careful, it's a closed source jar!
[https://github.com/francescotescari/XiaoMiToolV2/pull/98](https://github.com/francescotescari/XiaoMiToolV2/pull/98) -\> tool cannot unlock anymore now.

#### Option \#2 - using MTKClient

1. Install [https://github.com/bkerler/mtkclient](https://github.com/bkerler/mtkclient) (some distros have the package, for example: mtkclient-git in AUR).
2. Power off the phone and turn it on while holding Volume Up.
3. Backup preloader and run `mtk da seccfg unlock` ( [original source](https://github.com/bkerler/mtkclient/blob/main/README-USAGE.md#unlock-bootloader), [found reference](https://gist.github.com/javashin/0df28ef72057552549622d3eae36fb79))

### Installing via fastboot

```
$ pmbootstrap init
$ pmbootstrap install
$ pmbootstrap flasher flash_rootfs
$ pmbootstrap flasher flash_kernel
$ fastboot reboot
```

In case of bootloop, run `pmbootstrap flasher flash_vbmeta` (partition name "vbmeta") and then flash\_kernel.

### Installing via recovery mode

```
$ pmbootstrap init
$ pmbootstrap install --android-recovery-zip
$ pmbootstrap export
```

Then transfer the zip to the device:

```
$ adb push /tmp/postmarketOS-export/pmos-xiaomi-begonia.zip /sdcard
```

Flash the zip and reboot.

## Unbricking

If something went terribly wrong (e.g. boot.img doesn't contain valid DTB), your device will hard-brick. Fortunately it's easy to unbrick the device.

Requirements (GNU/Linux):

- Kernel patched with [this patch](https://github.com/amonet-kamakiri/kamakiri/blob/master/kernel.patch)
- Python3: `pyusb pyserial json5`
- SP Flash Tool (tested with version 5.2208)
- [Mediatek Bypass utility](https://github.com/MTK-bypass/bypass_utility)
- Known working partitions (from backup or [Android ROM](https://forum.xda-developers.com/t/rom-10-0-unofficial-lineageos-17-1-begonia-begoniain.4072137/))
- [MT6785 scatter file](https://gist.github.com/michaelskyf/eff1894ec531e659f2a2ec393ba61697)

Steps:

1. Run the exploit
2. Connect the device via USB and hold Volume Up (+)
3. When "Protection disabled" message appears, open SP Flash Tool
4. Select partition images that you want to write and click Download [for info/steps](https://www.youtube.com/watch?v=wm0UFvjSvVg)
5. After green checkmark image appears, restart your phone

### Booting process

[More info](https://medium.com/swlh/modding-the-redmi-note-8-pro-an-adventure-e473e84d4d14)

1. BROM (Boot ROM)
Boots when power is applied to SoC. Initializes flash storage and starts preloader.
2. PL (Preloader)
Initializes basic devices like USB, GPIO, timers, etc. If Volume Up is held, PL will hand control back to BROM wth EDL (Emergency Download Mode).
3. LK (Little Kernel)
Displays logo and verifies some partitions (TODO: which partitions?). If it fails to verify partition, it won't continue.
