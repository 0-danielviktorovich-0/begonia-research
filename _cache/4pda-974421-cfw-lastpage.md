\- wider control center tiles

\- restoring a Google backup no longer turns on "Make more apps dark"

\- theme Store is back

\- dark mode schedule fixed

\- high-end ColorOS animation level set

Внимание! Прошивка не тестировалась. Ставьте на свой страх и риск!

#

Способ установки

Clean Flashing:

1.Flash Unified TWRP

3.Select Wipe > Advance Wipe

5.Select Install > Flash ROM

6.Select Wipe > Format Data > Type "yes"

Dirty Flashing:

2\. Select Install > Select the ROM file > Swipe to Flash

3\. Flash KSU kernel OR Magisk(if flashed previously)

If there's an error in data formatting, just go back and re-run the process

#

Дополнения

• Dirty flash from ColorOS 16 supported

• Based off OnePlus Ace 3 Racing Edition firmware

• Use this manager for root(прикреплено)

• Dynamic build only, use Unifed TWRP(прикреплено)

• Includes Stock Miui Camera, Google Setup Wizard, etc.

• Phone will be unstable for a day, give it time to settle

• Kaorios Toolbox built in (enable fallback root and give it root thru KSU Manager)

\- fix rild

#

Способ установки

Clean Flashing:

1.Flash Unified TWRP

2.Reboot into your TWRP

3.Select Wipe > Advance Wipe

4.Select System, Vendor, Dalvik, Cache

5.Select Install > Flash ROM

6.Select Wipe > Format Data > Type "yes"

7.Reboot to System

Dirty Flashing:

1\. Reboot to Recovery

2\. Select Install > Select the ROM file > Swipe to Flash

3\. Flash KSU kernel OR Magisk(if flashed previously)

4\. Reboot to System

If there's an error in data formatting, just go back and re-run the process

#

Дополнения

• Dirty Flash from ColorOS 16/previous release supported

• Based off OnePlus Ace 5 Racing Edition Firmware

• Use this manager for root

• Dynamic Build Only, use Unifed TWRP

• Includes stock Miui Camera, Google Setup Wizard, etc.

• Phone will be unstable for a day, give it time to settle

• Kaorios Toolbox built in (Enable fallback root and give it root thru KSU Manager

• AOD screen off animation may get interrupted by black screen after reboot, turn AOD on and off to fix

Способ установки

Clean Flashing:

1.Flash Unified TWRP

3.Select Wipe > Advance Wipe

4.Select System, Vendor, Dalvik, Cache

6.Select Wipe > Format Data > Type "yes"

7.Reboot to System

Dirty Flashing:

1\. Reboot to Recovery

2\. Select Install > Select the ROM file > Swipe to Flash

3\. Flash KSU kernel OR Magisk(if flashed previously)

4\. Reboot to System

If there's an error in data formatting, just go back and re-run the process

#

Способ установки

**UEFI:**

fastboot flash boot UEFI.img

\-\-\--------------------------------------------------------------------------------------------

**WinPE:**

1\. Скачиваем "WinPE\_BEGONIA\_ARM64.iso"

2\. Форматируем SD-карту\* в FAT32 с разметкой GPT (желательно через diskpart)

3\. Через [Rufus](https://4pda.to/stat/go?url=https%3A%2F%2Frufus.ie%2Fen%2F&e=146118602 "Ссылка") форматируем SD-карту под WinPE

4\. Подключаем к телефону, включаем и ждём. долго ждём. (ожидание может занимать от 5 до часа, как повезёт)

\-\-\--------------------------------------------------------------------------------------------------------------------------------------

**ФОРМАТИРОВАНИЕ SD-КАРТЫ В DISKPART**

diskpart

list disk

select disk X (X - буква вашей SD-карты)

clean

convert gpt

create partition primary

format fs=fat32 quick

assign letter=S (можно любую другую свободную, кроме X!)

exit
