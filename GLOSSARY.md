# GLOSSARY — begonia-research

- **begonia** — Xiaomi Redmi Note 8 Pro (MT6785/G90T).
- **PoWeR kernel** — линия ядер мейнтейнера Saikrishna1504 (4.14.357-openela; 4.19.325-cip136-st20 с ноября 2026).
- **R-OSS** — vendor-поколение MIUI 12.5 (Android 11), база прошивок begonia.
- **C2** — vendor-компонент, портированный из rosemary в Axion 2.9 (окт 2026).
- **Kaeru LK** — модифицированный загрузчик в Axion 2.9 (спуф залоченного BL).
- **ak3 / AnyKernel3** — формат установочного пакета ядра (recovery-flashable).
- **kbdev** — супервизор устройства на хосте: status/wait-boot/to-bootloader/restore/forensics.
- **ram_console** — MTK-область 0x4D000000 (64КБ) для предсмертных логов; пишется только ядрами с CONFIG_MTK_RAM_CONSOLE.
- **kbild-N** — нумерация наших сборок в контейнере halium-builder:native.
- **CIP** — Civil Infrastructure Platform (kernel.org, долгие стабильные ветки: 4.19.y-cip).
