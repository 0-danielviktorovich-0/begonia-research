Данная инструкция проверена на моём телефоне 6/128 с прошивкой GLOBAL V10.4.5.0.PGGEUXM и подходит для китайцев(перешитых на Индонезию), а также для телефонов с индексом RU! … Всё делаете на свой страх и риск! ВСЕ ДАННЫЕ НА ТЕЛЕФОНЕ СТИРАЮТСЯ! Данная инструкция ориентирована на рядовых пользователей. Загрузчик должен быть разблокирован!

ИНСТРУМЕНТАРИЙ (спойлер, раскрыт 2026-11-21): 1. Отключенная подпись драйверов на Windows. Обязательно установленные на комп драйвера для процессоров MTK Driver_Auto_Installer_EXE_v5.1632.00 из шапки. 2. Пакет ADB, распаковать в корневую папку на диске C. ADB.rar (1.44 МБ) [attach 17680733] Внимание! Файлы из пунктов 3, 3.1 применяются, по необходимости, только для спойлера “Если что-то пошло не так” в конце данной инструкции! Если у Вас прошивка не EU, то нужно использовать boot.img ИМЕННО от своей текущей прошивки! 3. Стоковый boot.img от MIUI10 EU, прошивка этого файла на MIUI11 превращает телефон в КИРПИЧ: boot_V10.4.5.0.zip (9.88 МБ) [attach 17680781] 3.1. Стоковый boot.img от MIUI11 EU: boot_V11.0.1.0.zip (10.76 МБ) [attach 17979703] 4. Сам TWRP: twrp-3.3.1-9-begonia.zip (34.14 МБ) [attach 17680925] 5. Прямые руки и терпение.

ПОРЯДОК ДЕЙСТВИЙ (спойлер, раскрыт 2026-11-21): 0. Зарядить телефон более чем на 30%. 1. Активируем меню разработчика. 2. Включаем Отладку по USB. 3. Устанавливаем драйвера из Driver_Auto_Installer_EXE. 4. Подключаем включенное тело к ПК для установки драйверов (ADB… и переносное устройство). 5. Отключаем и штатно выключаем. 6. Зажимаем Volume- и Power до “зайца в ушанке” и FASTBOOT; подключаем к ПК. Пункты 7,8,9 — установка TWRP вручную. АВТОМАТИЧЕСКАЯ УСТАНОВКА TWRP: распаковываем ifelixit FLASHER TOOLKIT Begonia.bat на диск C, в окнах дважды “1”+Enter; в конце обязательно OKAY! Сразу отключаем телефон от ПК, иначе командой уйдёт в перезагрузку и восстановится стоковый recovery. [attach: ifelixit FLASHER TOOLKIT Begonia.zip 34.69 МБ] 7. В папку ADB копируем recovery.img. 8. Открываем cmd в папке ADB. 9. fastboot devices; затем: fastboot flash recovery recovery.img → OKAY! 10. Отключаем от ПК, зажимаем Power, при погасшем экране сразу Volume+ и держим; через две заставки TWRP отпускаем. Свайп вправо. Китайский язык → английский. Окно пароля = шифрование DATA → CANCEL. Монтирование: галки data, system, vendor, nvdata и MicroSD (если есть). Advanced → File Manager → system_root/system/ → в самом низу удаляем файл recovery_fromboot.p. Advanced → Close AVB2.0 → прошиваем архив свайпом (AVB2.0 снимает запрет на внесение изменений в данные). Install → Select Storage → Internal Storage OK → папка supersu → SuperSu_installer.zip → прошиваем свайпом. Это архив с Magisk_19.4, он пропатчит boot. Прошивка должна пройти БЕЗ единой ошибки, все строки белые, в конце DONE. Reboot → System. Первая загрузка долгая. Запускаем Magisk_Manager, обновляем менеджер и Magisk.zip (прямая установка), источник — стабильный канал. ROOT ПОЛУЧЕН!

ЕСЛИ ЧТО-ТО ПОШЛО НЕ ТАК (спойлер): 1. В папку ADB копируем распакованный boot.img (п.2;3;3.1). 2. Пункт 8. 3. fastboot flash boot boot.img и fastboot flash recovery recovery.img — прошили чистый boot и TWRP. 4. Пункт 10 (recovery_fromboot.p уже удалён). 5. В TWRP Mount проверяем галки data, system, vendor, nvdata — ставятся и снимаются. 6. Можно расшифровать DATA форматированием: Wipe → Format Data → yes. 7. Повторяем пункт 10.

ЗАВОДИМ GPAY (спойлер): 1. Качаем Gpay из маркета, не запускаем. 2. Magisk Manager → Magisk Hide — галки как на скрине. 3. Модуль для Magisk Crea GPay[1].zip (8.24 МБ). 4. Перезагрузка и привязка карты.
